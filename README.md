# Kotlin Java-Roadmap Practice 🛣️

I'm following the Java roadmap, but writing everything in **Kotlin**.
Each topic gets one console project to test what I've learned, and the
last project combines all of them.

No Android here, just logic, structure, and clean code.

## Projects

| # | Topic | Project | Status |
|---|-------|---------|--------|
| 1 | Basics | Student Score Analyzer | ⬜ |
| 2 | OOP | Payroll System | ⬜ |
| 3 | Collections | Contact Book (generic `Repository<T>`) | ⬜ |
| 4 | Exception Handling | ATM Simulator | ⬜ |
| 5 | File I/O | Expense Tracker | ⬜ |
| 🏁 | All of the above | Bank CLI | ⬜ |

## What each project covers

- **Student Score Analyzer**: variables, loops, arrays, control flow
- **Payroll System**: inheritance, polymorphism, abstraction, encapsulation
- **Contact Book**: List/Set/Map, generics, iterators
- **ATM Simulator**: try/catch, throw, custom exceptions
- **Expense Tracker**: BufferedReader/Writer, serialization
- **Bank CLI**: everything combined (menu loop, account hierarchy, maps, custom exceptions, saving/loading data)

## How to run

1. Clone the repo
   ```bash
   git clone https://github.com/<your-username>/kotlin-java-roadmap-practice.git
   ```
2. Open the project folder in IntelliJ IDEA (or any Kotlin-ready IDE).
3. Run the `main()` function in the project you want.
